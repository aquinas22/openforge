# OpenForge icon

Generated with the built-in imagegen tool with a transparent background.
The original generated asset is src/renderer/src/assets/art/openforge-icon.png.
The sidebar and splash screen use openforge-icon-512.png; desktop packaging
uses build/icon.png and the multi-resolution Windows build/icon.ico.
ImageMagick produced the resized PNG and ICO while preserving transparency.

## Generation prompt

Use case: logo-brand. Asset type: square desktop application icon and small
sidebar logo for OpenForge, a Minecraft launcher. Primary request: an anvil that
is hollowed out, with the outline of a forge and fire in the background. Create
one polished, centered, bold icon: a recognizable side-profile anvil in front,
constructed as a thick dark iron outline with a clearly hollow negative-space
interior; behind it a simple thick outline of an arched forge furnace containing
stylized glowing orange and golden fire. The fire is visible through the hollow
anvil and above its top. Crisp silhouette, strong contrast, clean simplified
shapes that remain readable at 32 pixels. Balanced square composition, complete
icon in frame with about 8 percent transparent padding. Actual transparent
background outside the forge outline; preserve transparent negative space where
appropriate. No words, no letters, no badge, no extra tools, no watermark, no
mockup, no scenery. Produce a single high resolution finished icon.
